# Etapa 3 — Materialização com agente Antigravity

## Objetivo

Usar um agente para transformar o plano criado com o Copilot em arquivos Markdown organizados, fáceis de consultar e atualizar.

## Arquivos produzidos

- [`../cronograma.md`](../cronograma.md) — roteiro de 30 dias, distribuído em semanas e dias.
- [`../recursos.md`](../recursos.md) — materiais e referências de apoio por semana.
- [`../anotacoes/semana-01.md`](../anotacoes/semana-01.md) — modelo de diário e checklist semanal.
- `README.md` — texto de apresentação que acompanhava os arquivos gerados; este repositório tem um README principal reorganizado para destacar o fluxo do desafio.

## Como os arquivos foram preparados para este repositório

O conteúdo do agente foi incorporado como resultado da etapa. Caminhos locais do computador, como links `file:///...`, não são portáveis e foram substituídos por links relativos do repositório. O cronograma e os materiais são apresentados como saídas do processo, não como foco principal do projeto.

## Revisão recomendada

Antes de usar ou publicar arquivos gerados por IA, confira links, nomes de funções, compatibilidade de ferramentas, sequência dos tópicos e consistência entre os documentos.
