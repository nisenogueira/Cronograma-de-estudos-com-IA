# Study Quest — Aplicativo criado no Lovable

Este aplicativo é o resultado da quarta etapa do desafio. A autora levou os materiais produzidos anteriormente ao Lovable e criou uma experiência gamificada para tornar o acompanhamento dos estudos mais envolvente.

## Recursos apresentados

- Missões diárias e semanais
- XP, moedas virtuais e níveis
- Metas e recompensas
- Links de estudo associados aos temas
