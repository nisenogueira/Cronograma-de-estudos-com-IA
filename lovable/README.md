# Study Quest

O Study Quest é o aplicativo gamificado criado a partir do cronograma de estudos. A experiência transforma os 30 dias em missões diárias e semanais.

## Recursos

- XP por atividades concluídas
- Moedas virtuais
- Níveis e progresso
- Metas diárias e semanais
- Premiações configuráveis
- Links de estudo para os temas do dia
